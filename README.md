### What is it

Minijam 222 submission.
Theme: Enchanted
Limitation: Now featuring cats

### Setup

```
npm run setup
```

Will install all needed packages

### Compile

```
npm run build
```

or for watch build of game files which will auto rebuild as soon as a file is saved.

```
npm run dev
```

There are tasks setup for this if you are using vscode (located in the .vscode folder)

### Formatting

```
npm run format
```

### Running

```
npm run host
# Then open http://localhost:8080/ in browser of your choice 
```
